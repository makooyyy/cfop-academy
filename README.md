# CFOP Academy

Русскоязычный учебный сайт по методу Фридрих (CFOP) для кубика 3×3.

**Сайт:** https://makooyyy.github.io/cfop-academy/

## Возможности

- 13 уроков: устройство кубика, нотация, крест, интуитивный F2L, 2-look OLL/PLL, полная сборка и переход к полному CFOP.
- 57 OLL и 21 PLL: поиск, группы, базовые случаи, отметки изучения.
- Собственная модель из 54 наклеек: объёмная схема, развёртка шести граней, просмотр каждого хода, воспроизведение с тремя скоростями, обратные формулы подготовки.
- Тренировочные примеры для F2L и ориентации рёбер; ввод своей последовательности.
- Таймер с перемешиваниями, ao5, +2/DNF, историей до 500 попыток и экспортом CSV.
- Адаптивный интерфейс и локальное сохранение прогресса без регистрации.
- Светлая и тёмная темы: при первом посещении учитывается тема системы, ручной выбор сохраняется между сеансами.
- Основные материалы доступны офлайн после первого успешного посещения сайта.

Для работы с курсом нужен физический кубик. Сайт показывает учебные случаи; он не распознаёт кубик камерой и не вычисляет решение произвольного введённого состояния. Домашние перемешивания состоят из случайных ходов, а не равномерно случайных состояний WCA.

## Локальный запуск

Нужен Node.js 20 или новее. Внешних npm-зависимостей нет.

```sh
npm start
```

Открыть http://127.0.0.1:4178. ES-модули требуют HTTP-сервер: открытие index.html через file:// не поддерживается.

```sh
npm test
```

Проверяются направления ходов, повороты слоёв, сохранение F2L всеми алгоритмами последнего слоя, 57 уникальных OLL-паттернов, обратные последовательности, учебные примеры и расчёт ao5 с DNF/+2.

## Публикация

Статический сайт без сборки. GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). Все ссылки относительные, чтобы сайт работал в подпапке репозитория. `.nojekyll` отключает обработку Jekyll.

При изменении перечня офлайн-файлов обновить `FILES` и версию `CACHE` в `sw.js`.

## Структура

- `app.js` — интерфейс и состояние.
- `cube.js` — геометрическая модель, нотация и SVG.
- `lessons.js` — авторские русскоязычные уроки и примеры.
- `algorithms.js` — стандартные последовательности OLL/PLL.
- `stats.js` — расчёт результатов.
- `tests/cube.test.mjs` — проверки математических свойств.

## Учебные источники

Стандартные последовательности ходов сверены по [J Perm OLL](https://jperm.net/algs/oll) и [J Perm PLL](https://jperm.net/algs/pll). В Aa, Ab, E и Ja добавлен обратный поворот всего кубика в конце для сохранения одинакового начального хвата во всех схемах. Тексты уроков и SVG-модель созданы для проекта. Код и изображения сторонних тренажёров не используются.

Дополнительные материалы: [J Perm CFOP](https://jperm.net/3x3/cfop), [CubeSkills F2L](https://www.cubeskills.com/tutorials/f2l).

Прогресс хранится только в localStorage текущего браузера. Очистка данных сайта удалит его. Внешние материалы и загрузка шрифта Google Fonts требуют сети; при недоступности шрифта используется системный.
